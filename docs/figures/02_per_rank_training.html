Figure 2. Per-rank heterogeneous terrain training. A single SplitMoEActorCritic is replicated to 8 GPUs via PyTorch DDP. Each rank instantiates the same network but a different terrain generator (mixed baseline · stair-only · pit/box platform · hurdle scan · stepping stones · rails · random rough · flat + slope), and three ranks (1, 2, 3) apply targeted reward overrides that match the locomotion regime of their assigned terrain. Hard-terrain ranks disable illegal_contact termination to permit a "crash-then-climb" exploration strategy. Gradients are averaged across all 8 ranks via NCCL all-reduce on every PPO backward pass; logging is split between a shared wandb run and per-rank jsonl scratch files (the latter avoids a prior all-gather deadlock observed during development).
